# Lab 01 — Bài 05 Tasks

## Goal

Build a simple Windows-style calculator.

Minimum requirements:

- integer input,
- decimal input,
- addition,
- subtraction,
- multiplication,
- division.

## State Design

Recommended state:

```text
currentValue
firstOperand
currentOperator
isNewNumber
```

## Logic Tasks

- [ ] Create `CalculatorLogic`
- [ ] Support `+`
- [ ] Support `-`
- [ ] Support `*`
- [ ] Support `/`
- [ ] Handle decimal values
- [ ] Handle division by zero
- [ ] Handle repeated operations
- [ ] Reset calculator state

## Validation / Behavior Tasks

- [ ] Prevent multiple decimal points
- [ ] Handle divide-by-zero safely
- [ ] Handle repeated equals
