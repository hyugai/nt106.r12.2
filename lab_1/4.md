# Lab 01 — Bài 04 Tasks

## Goal

Given integers `A` and `B`, calculate:

```text
A!
B!
S1 = 1 + 2 + ... + A
S2 = 1 + 2 + ... + B
S3 = A^1 + A^2 + ... + A^B
```

Create `Bai04Logic` with separate methods:

- [ ] `Factorial(int n)`
- [ ] `SumTo(int n)`
- [ ] `PowerSum(int a, int b)`
