# Lab 01 — Bài 01 Tasks

## Goal

Create a WinForms program that accepts **3 numbers** and displays the **largest** and **smallest** values.

## Logic Tasks

- [ ] Define input values `a`, `b`, `c`
- [ ] Implement max calculation
- [ ] Implement min calculation
- [ ] Keep logic outside `Designer.cs`
- [ ] Prefer a dedicated `Bai01Logic` class

## UI Tasks

- [ ] Create `Lab01_Bai01` Form
- [ ] Add 3 input TextBoxes
- [ ] Add `Tính` button
- [ ] Add `Xóa` button
- [ ] Add `Thoát` button
- [ ] Add output field for largest value
- [ ] Add output field for smallest value
- [ ] Use clear control names such as `txtA`, `txtB`, `txtC`

## Validation Tasks

- [ ] Empty input
- [ ] Invalid text input
- [ ] Negative values
- [ ] Equal values
- [ ] Decimal values if supported

## Test Cases

- [ ] `1, 2, 3`
- [ ] `3, 2, 1`
- [ ] `3, 3, 3`
- [ ] `-10, 0, 5`
- [ ] invalid text
- [ ] empty field

## Done When

- [ ] Max/min results are correct
- [ ] Invalid input does not crash
- [ ] Clear button resets fields
- [ ] Exit button works
- [ ] Form works through MainForm navigation
