# Lab 01 — Bài 02 Tasks

## Goal

Read an integer from **0 to 9** and display the number in Vietnamese words.

Example:

```text
1 -> Một
2 -> Hai
0 -> Không
```

## Logic Tasks

- [ ] Create `Bai02Logic`
- [ ] Implement digit conversion using `switch` or switch expression
- [ ] Return a readable result
- [ ] Reject values outside `0..9`
